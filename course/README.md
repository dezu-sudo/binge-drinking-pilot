# Interactive Course: Epidemiological Analysis of Binge Drinking Trends with BRFSS

This course teaches you to conduct a national-scale, publication-ready epidemiological
surveillance analysis using the CDC's Behavioral Risk Factor Surveillance System (BRFSS).
The content is derived directly from a 14-year (2011–2024) analysis of U.S. binge drinking
trends across all 50 states and D.C.

---

## Course Structure

| Module | File | Topic |
|--------|------|-------|
| 1 | `01-introduction.Rmd` | BRFSS overview, binge drinking definition, survey design basics |
| 2 | `02-loading-auditing.Rmd` | Loading XPT files, `find_var()`, variable auditing across years |
| 3 | `03-harmonization.Rmd` | Recoding outcomes, age, race/ethnicity, education, income |
| 4 | `04-survey-design.Rmd` | Building `svydesign` objects, pooling years, subsetting designs |
| 5 | `05-prevalence.Rmd` | `svymean()`, `svyby()`, annual trend loops, BH correction |
| 6 | `06-age-standardization.Rmd` | Year 2000 standard population, `svystandardize()` |
| 7 | `07-stratified-analysis.Rmd` | Stratified trends, state rankings, joinpoint export |
| 8 | `08-visualization.Rmd` | ggplot2 trend plots, CI ribbons, facets, heatmaps |
| 9 | `09-regression.Rmd` | PR models, COVID sensitivity, Race×Time and Sex×Time interactions |

**Support file:** `synthetic_brfss.R` — generates realistic synthetic BRFSS-like data for
all in-course exercises. No real BRFSS data is required to run the tutorials.

## Running the Tutorials

### Prerequisites

Install required R packages:

```r
install.packages(c(
  "learnr", "tidyverse", "haven", "janitor",
  "survey", "srvyr", "scales", "purrr"
))
```

### Launch a single module

```r
learnr::run_tutorial("01-introduction", package = NULL)
# or open the .Rmd directly in RStudio and click "Run Document"
```

Or run from the `course/` directory:

```r
setwd("course/")
rmarkdown::run("01-introduction.Rmd")
```

### Launch all modules (one at a time)

Each `.Rmd` file is a self-contained interactive tutorial. Open any module in RStudio
and click the **"Run Document"** button, or call `rmarkdown::run("<file>.Rmd")`.

## What You Will Learn

By the end of this course you will be able to:

- Load and harmonize multi-year BRFSS XPT files with consistent variable naming
- Build complex survey design objects that correctly account for PSUs, strata, and weights
- Compute age-standardized prevalence estimates and confidence intervals
- Produce stratified trend estimates by sex, race/ethnicity, education, and income
- Conduct state-level analyses and generate state rankings
- Build publication-quality ggplot2 figures with CI ribbons and trend annotations
- Fit Prevalence Ratio regression models using `svyglm()` with `quasipoisson`
- Test for effect modification (Year × Race, Year × Sex interactions) using joint Wald tests
- Apply Benjamini-Hochberg multiple comparisons correction

## Data Note

All in-course exercises use **synthetic data** generated by `synthetic_brfss.R`.
The synthetic data mimics the structure, variable names, and approximate prevalence
patterns of real BRFSS data but contains no real respondent information.

To run the full analysis pipeline with real data:

1. Download BRFSS LLCP files from [cdc.gov/brfss](https://www.cdc.gov/brfss/annual_data/annual_data.htm)
2. Place each year's file at `data/raw/<year>/LLCP<year>.XPT` (or `.XPT_`)
3. Update `PROJ_DIR` in `main_run_2011_2024.R`
4. Run `main_run_2011_2024.R` end-to-end

The caching system (`read_year_cached`) will process each year once and save `.rds`
files — subsequent runs load instantly from cache.
